# Stop Testing Circuit Boards by Hand. Build This.

Welcome to the companion repository for our video: **https://youtu.be/ITH-iNQU9S0**.

This repository contains the hardware parts list and the 3D model files needed to build the custom PCB test jig featured in the video. 

---

## Repository Contents

* **`step_file/`**: This directory contains all the 3D models (STEP files) required for 3D printing the test jig components.

---

## Parts List

Below is the hardware needed to assemble the physical mechanism of the test jig:

* **4x Linear Motion Shafts** (8mm diameter, H6, 200mm length)
  * *Example:* [Dold Mechatronik - CF53 8mm Shaft](https://www.dold-mechatronik.de/Praezisionswelle-8mm-h6-geschliffen-und-gehaertet-Material-CF53-Zuschnitt)
* **4x Linear Ball Bearings** (8mm diameter)
  * *Example:* [Dold Mechatronik - KH0824-PP Bearing](https://www.dold-mechatronik.de/Kompakt-Linearkugellager-KH0824-PP)
* **M3 Brass Heat-Set Inserts** (Length depending on which type of heat-set inserts you are using)
* **Shoulder Screw M3** (4*4mm)
* **Shoulder Screw M3** (4*8mm)
* **RL75-4S Receptacles** (Available on AliExpress)
* **PAL75-Q1 Pogo Pins** (Available on AliExpress)
